# Triple homeland

Hola, en este nuevo proyecto se desarrolló la página web para mostrar las ciudades natales de algunos empleados de TripleTen.

Se trabajó con diseños en un editor gráfico llamado Figma, se utilizaron consultas de medios (media queries) para establecer parámetros para diferentes tamaños de pantallas y se utilizó la metodologia BEM para organizar los archivos.
